Algorithm pipeline CSP P = (X, D, C)
  1. Conflict graph: vertices are course events, edges are same-timeslot clashes.
  2. Welsh-Powell: colors high-degree vertices first to produce timeslot warm starts.
  3. AC-3: prunes unsupported timeslot-room values from domains.
  4. MAC backtracking: uses MRV and LCV while enforcing hard constraints.
  5. Soft scoring: measures gaps, preferences, transitions, and edge-hour overload.
